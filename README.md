# chessEngine

-Alpha-Beta Pruning** – Efficient minimax implementation to reduce unnecessary search.
-Iterative Deepening** – Ensures best move found within time constraints.
- Quiescence Search** – Extends leaf nodes to avoid horizon effects from noisy positions.
- Transposition Tables** – Avoids redundant calculations using hash tables.
- Polyglot Opening Book** – Supports `.bin` books for solid openings.
- MVV/LVA Move Ordering** – Optimized move sorting based on Most Valuable Victim / Least Valuable Attacker.
- UCI Protocol – Compatible with GUIs like [Arena, CuteChess, etc.].
